# 📊 Netflix Dashboard 2021

An interactive Power BI dashboard analyzing Netflix's catalog of movies and TV shows, built from the public `netflix_titles.csv` dataset.

## 🔍 Overview

This project explores trends in Netflix content — such as the split between movies and TV shows, content added by year, top genres, and country-wise distribution — through an interactive Power BI report.

## 📁 Files in this Repo

| File | Description |
|------|-------------|
| `netflix_titles.csv` | Raw dataset containing details of Netflix titles (type, title, director, cast, country, release year, rating, duration, genre, etc.) |
| `netflix_board.pbix` | Power BI dashboard file with visualizations and insights built on the dataset |

## 📈 Dashboard Highlights

- Movies vs TV Shows distribution
- Content added over the years (trend analysis)
- Top countries producing Netflix content
- Most common genres/categories
- Rating distribution (TV-MA, PG-13, etc.)
- Filters/slicers for interactive exploration by year, type, country, and genre

## 🛠️ Tools Used

- **Power BI Desktop** – for building the dashboard
- **CSV/Excel** – as the data source

## 🚀 How to View

1. Clone or download this repository.
2. Open `netflix_board.pbix` in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free to download).
3. Explore the interactive visuals and filters.

## 📌 Dataset Source

The dataset used is the publicly available Netflix Movies and TV Shows dataset (commonly sourced from [Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)).
